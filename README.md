# Университетская дача — приватный концепт

Персональный лендинг для кандидата C-079 из рабочей базы лидов. Проект не является официальным сайтом организации и не предназначен для публичного размещения без согласования материалов и фактов.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Источники фактов

- Яндекс Карты: https://yandex.com/maps/org/universitetskaya_dacha/2476452892/
- Веб-поиск по названию, адресу и телефону выполнен 2026-09-11.
- Рабочий бриф: `BRIEF.md`.

## Материалы

`public/hero-concept.webp` создан специально для этого приватного демо. Это художественная иллюстрация и она не изображает реальный гостевой дом.
